# **Códigos Capítulo 2 Detecção materno-fetal do vírus da raiva no morcego-vampiro *Desmodus rotundus*, Brasil**

Códigos utilizados para processamento de dados e produção de gráficos do Capítulo 2 da Tese de Doutorado, publicados no artigo "Maternal-fetal detection of rabies virus in the vampire bat *Desmodus rotundus*, Brazil" na revista EMI: Animal & Enviroment (doi:10.1080/29986990.2026.2644111).

1-sangerseqR-severalFASTA.R : script em R para processar sequências de Sanger em formato ab1
2-function_seq_filter_list : função para filtrar sequências de arquivos GenBank (.gb) a partir da presença de rótulos.
2-lyssa-genbank-filter.ipynb : notebook com etapas para filtragem de sequências da vírus da raiva obtidas do Genbank a partir de metadados e comprimento das sequências. 
3-grafico-reads-pools.R : script para a produção da Figura 1A do capítulo
3-grafico-reads-rnaseq-vsp.R : script para a produção da Figura 1B do capítulo
